# Stan Smit - Software Engineering Portfolio

Personal portfolio website showcasing my experience in C#/.NET backend development, software architecture, cloud services, quality-focused engineering, and independent game development.

## About

This project is a responsive portfolio website built with HTML, CSS, JavaScript, and Bootstrap.

It highlights:

- C#/.NET Backend Development
- ASP.NET Core and REST APIs
- Software Architecture and System Design
- Azure, Cosmos DB, and Application Insights
- Multithreading, Concurrency, and Microservices
- Quality Engineering and Automation Experience
- Independent Game Development with C# and Unity
- Professional Experience, Education, and Downloadable Resumes

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Features

- Responsive modern layout
- Professional software engineering profile
- Backend, software engineering, and game development skill sections
- Experience cards with technologies and responsibilities
- Education section
- LinkedIn, GitHub, and email contact links
- Downloadable Classic and Visual resume PDFs
